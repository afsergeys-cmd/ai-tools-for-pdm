# «Кто выгуливает Бориса»

Учебный Node.js micro-MVP для вымышленной компании «Догяндекс». Сотрудник выбирает один из пяти свободных слотов прогулки с собакой Борисом на текущую дату, вводит синтетическое ФИО и получает подтверждённую запись. На странице также отображается информация о последнем кормлении.

## Пользователь

Сотрудник компании, которому нужно самостоятельно выбрать время прогулки с Борисом и убедиться, что слот не занят другим сотрудником.

## Возможности

- просмотр текущей даты и пяти фиксированных слотов: `09:00`, `11:00`, `13:00`, `15:00`, `17:00`;
- запись на свободный слот с серверной проверкой имени и фамилии;
- отображение занятого слота и ФИО записавшегося сотрудника;
- серверный отказ при повторной попытке занять занятый слот;
- сохранение записей в SQLite после обновления страницы и открытия приложения в другом браузере;
- отметка нового кормления и отображение времени и ФИО последнего сотрудника.

## Состав страницы

- шапка с названием проекта и текущей датой;
- первый экран с коротким объяснением сценария;
- заметный блок «Прогулка с Борисом сегодня» с пятью слотами;
- карточка «Последнее кормление»;
- три коротких шага: выбрать свободное время, указать ФИО, получить подтверждение.

## Технологии

- Node.js и npm;
- встроенный `node:sqlite` (Node.js 22.5 или новее), без сторонних npm-зависимостей;
- HTML, CSS и JavaScript в одном `index.html`;
- HTTP-сервер Node.js в `server.js`.

## Быстрый запуск

Установите Node.js версии 22.5 или новее. В папке проекта выполните `npm start`, затем откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Сторонние пакеты устанавливать не требуется.

## Запуск

Запустите локальный Node.js-сервер командой `npm start` и откройте страницу в браузере. Данные хранятся в файле `boris.sqlite`, который автоматически создаётся в папке проекта.

## Границы проекта

В текущую версию не входят авторизация, роли, личный кабинет, отмена записи, редактирование ФИО, календарь на неделю, история действий, уведомления, внешние интеграции, администрирование и обязательный деплой.

## Проверка готовности

Готовность определяется семью критериями из `spec.md`: пять слотов и текущая дата, различие свободных и занятых слотов, успешная запись, серверный конфликт, сохранение в SQLite, обновление карточки кормления и работоспособность на широком и узком экране. Проверены ответ главной страницы (`200`), пять слотов, отклонение однословного имени (`400`), успешная запись (`201`), повторная запись (`409`) и сохранение в SQLite после перезагрузки страницы. Для подтверждения вторым браузером и полного прохода на узком экране требуется отдельная ручная проверка.

## Локальные ограничения

Приложение предназначено для локального запуска. Используются только синтетические ФИО и данные; реальные персональные данные, секреты, сетевые запросы и внешние сервисы не нужны. Функции вне сценария записи на прогулку и отметки последнего кормления не добавляются.
