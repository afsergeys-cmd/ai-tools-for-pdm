# Кто выгуливает Бориса

## Гипотеза

Если сотрудник видит пять свободных и занятых слотов на сегодня, он сможет самостоятельно выбрать время прогулки и сохранить запись без обращения к администратору.

## Главный сценарий

Сотрудник открывает общую страницу, видит дату и пять слотов, выбирает свободный слот, вводит синтетическое ФИО и подтверждает запись. Слот становится занятым. Повторная попытка занять его получает отказ, а первоначальная запись сохраняется.

## Что построено

- локальное Node.js-приложение с общей адаптивной страницей;
- пять фиксированных времён прогулки на текущую московскую дату;
- атомарная серверная запись и хранение состояния в SQLite;
- компактная карточка последнего кормления.

## Результаты проверок

- главная страница возвращает HTTP 200, API выдаёт пять слотов;
- однословное значение отклоняется с HTTP 400;
- синтетическое имя и фамилия принимаются с HTTP 201;
- повторная запись в занятый слот отклоняется с HTTP 409;
- после перезагрузки страницы занятый слот и имя остаются видны;
- `node --check server.js` и `git diff --check` проходят.

## Границы

Это учебный локальный micro-MVP. В нём нет учётных записей, ролей, корпоративного справочника, отмены записи, календаря на неделю, уведомлений, внешних интеграций или production-инфраструктуры. Все демонстрационные имена должны быть синтетическими.
